무슨 의미일까?

경제 변수는 기업의 매출과 비용, 투자자의 기대에 영향을 줍니다. 원인과 결과를 구분해서 이해하는 것이 중요해요.

ETF에는 어떤 영향이 있을까?

SPY, QQQ, SOXX는 구성 업종과 기업이 달라 같은 경제 뉴스에도 서로 다른 반응을 보일 수 있어요.

차트와 가격은 모두 가상 예시이며 투자에 사용할 수 없습니다.

기간 선택은 UI 데모입니다. 실제 기간별 시세는 데이터 API 연결 후 제공됩니다.
